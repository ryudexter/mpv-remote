Where MPV Player Remote (`6823685362`) ranks on 2026-11-24, before it has any localization but en-US and before it
has a subtitle. Live: iOS 1.3, name "MPV Player Remote", no subtitle, en-US keywords
`video,mac,wifi,control,controller,media,movie,subtitles,playback,playlist,computer,film,tv,laptop`, primary category
Productivity. The lookup API lists the app in Japan and China with language `EN` only. 148 of 175 territories sell

## How it was measured

- **Suggestions:** `curl -s -H "X-Apple-Store-Front: <id>-1,29" "https://search.itunes.apple.com/WebObjects/MZSearchHints.woa/wa/hints?clientApplication=Software&term=<term>"`
  (a plist, most popular first, no counts). Storefront ids: us 143441, gb 143444, jp 143462, cn 143465, tw 143470,
  kr 143466, de 143443, fr 143442, ch 143459, ca 143455, ru 143469, mx 143468, br 143503, tr 143480.
- **Ranks:** `https://itunes.apple.com/search?term=<term>&country=<cc>&entity=software&limit=200`. It returns at
  most ~200 apps, so "not in" means below that or not matched. "Top-10 median" is the median `userRatingCount` of
  the first ten results: hundreds or fewer is thin, thousands is out of reach for an app with no ratings.
- 44 requests, one every 13 s, 19:11–19:23 local time (three other sessions shared the IP).

## What it shows

- **"mpv remote" is the one search the app nearly owns:** #2 in the US, the UK and Japan, behind "MPV Remote"
  (another developer, Oleksandr Vasyliev, 0 ratings, category Entertainment). Japan also suggests "mpv remote"
  for "mpv". IINA Remote (0 ratings) is the other app in that tiny Japanese list.
- **"mpv" on its own is weak:** #9 in the US, #89 in Korea, #126 in Türkiye, #163 in Russia, #164 in the UK, and not
  in the top ~190 in Japan or China, though the name starts with MPV. Apple fills "mpv" with video players (VLC,
  KMPlayer, Outplayer) and look-alikes (Mobile Passport Control, Npv Tunnel); in China "MPV Remote" is #2 where
  this app doesn't appear. The UK, Türkiye and Russia list no localization the app has, which fits; Japan does
  search en-US and still leaves it out, so downloads and perhaps the category (Productivity, where the players are
  Photo & Video or Entertainment) weigh in too.
- **Generic searches are out of reach:** "remote for mac", "computer remote", "media remote", "video player
  remote" and their local forms are led by Remote Mouse, TeamViewer, AnyDesk and TV remotes, with top-10 medians of
  600–6,300 ratings. The only thin ones are Korea "pc 리모컨" (median 67), Taiwan 電腦遙控器 (81) and China 电脑遥控器
  (188), all aimed at controlling a computer with a mouse/keyboard app. None lists this app.
- So the subtitle is written to make the listing clear to mpv users who find it through "mpv" / "mpv remote", with
  the words a remote for a video player is described by (video, subtitle, Wi-Fi, computer) rather than to win head
  terms. Only China's suggestion 电脑遥控器 backs a local name suffix (optional).

```python
"""python3 -I baseline.py <queries.tsv> <out.jsonl>  — one search every 13 s.
queries.tsv lines: h|r <TAB> cc <TAB> term"""
import json, plistlib, statistics, subprocess, sys, time, urllib.parse
APP = 6823685362
SF = {"us": 143441, "gb": 143444, "jp": 143462, "cn": 143465, "tw": 143470, "hk": 143463, "kr": 143466,
      "de": 143443, "fr": 143442, "ch": 143459, "ca": 143455, "ru": 143469, "mx": 143468, "br": 143503,
      "tr": 143480, "in": 143467, "es": 143454, "it": 143450, "au": 143460}
qs = [l.rstrip("\n").split("\t") for l in open(sys.argv[1], encoding="utf-8") if l.strip() and not l.startswith("#")]
out = open(sys.argv[2], "a", encoding="utf-8")
def curl(args):
    for attempt in range(3):
        r = subprocess.run(["curl", "-s", "-m", "30"] + args, capture_output=True)
        if r.returncode == 0 and r.stdout:
            return r.stdout
        time.sleep(20)
    return b""
for kind, cc, term in qs:
    t0 = time.time()
    rec = {"kind": kind, "cc": cc, "term": term}
    if kind == "h":
        url = ("https://search.itunes.apple.com/WebObjects/MZSearchHints.woa/wa/hints?clientApplication=Software&term="
               + urllib.parse.quote(term))
        raw = curl(["-H", f"X-Apple-Store-Front: {SF[cc]}-1,29", url])
        try:
            p = plistlib.loads(raw)
            rec["hints"] = [h.get("term") for h in p.get("hints", [])]
        except Exception as e:
            rec["error"] = f"{e}: {raw[:200]!r}"
    elif kind == "l":
        url = "https://itunes.apple.com/lookup?" + urllib.parse.urlencode({"id": term, "country": cc})
        raw = curl([url])
        try:
            res = json.loads(raw)["results"]
            rec["found"] = [(x.get("trackName"), x.get("userRatingCount", 0), x.get("version"), x.get("languageCodesISO2A"))
                            for x in res]
        except Exception as e:
            rec["error"] = f"{e}: {raw[:200]!r}"
    else:
        url = "https://itunes.apple.com/search?" + urllib.parse.urlencode(
            {"term": term, "country": cc, "entity": "software", "limit": 200})
        raw = curl([url])
        try:
            res = json.loads(raw)["results"]
            ids = [x["trackId"] for x in res]
            rec["rank"] = ids.index(APP) + 1 if APP in ids else None
            rec["n"] = len(res)
            top = [x.get("userRatingCount", 0) for x in res[:10]] or [0]
            rec["median"] = int(statistics.median(top))
            rec["max"] = max(top)
            rec["under100"] = sum(1 for x in top if x < 100)
            rec["top"] = [(x["trackName"], x.get("userRatingCount", 0)) for x in res[:5]]
            rec["topids"] = [(x["trackId"], x.get("sellerName"), x.get("primaryGenreName")) for x in res[:5]]
        except Exception as e:
            rec["error"] = f"{e}: {raw[:200]!r}"
    rec["at"] = time.strftime("%H:%M:%S")
    out.write(json.dumps(rec, ensure_ascii=False) + "\n"); out.flush()
    time.sleep(max(0, 13 - (time.time() - t0)))
```
